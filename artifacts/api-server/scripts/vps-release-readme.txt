관리자 주문 삭제는 완료/취소 건만 목록에서 제거하고 정산·회원 잔액·연결 기록을 보존합니다.
관리자 채팅거래 삭제는 종료된 주문 연결 방도 허용하며 대화·주문·정산을 보존합니다. 삭제된 항목 포함 보기와 삭제 시각·관리자 감사 정보를 제공합니다.
아이템마니아 수동 VPS 배포

이 패키지는 기존 수정 사항, 인게임 닉네임 분리 표시와 등록 시각의 한국 시간(KST) 고정 표시를 포함합니다.
채팅 상단에는 실제 거래번호와 거래일시를 추가하며, 거래 미생성 방은 채팅방 번호와 신청일시를 구분해 표시합니다.
채팅종료는 현재 사용자의 목록에서만 숨깁니다. 거래 상태·정산·대화 기록과 상대방 목록은 유지됩니다.
완료 카드의 클릭 방해를 제거하고, 목록이 길어져도 카드가 압축되지 않으며 새 신청/메시지를 자동 갱신합니다.
운영의 오래된 소스에서 다시 빌드하지 마세요.

1. itemmania-vps-release.tar.gz를 서버의 /root/에 업로드합니다.
2. root 터미널에서 실행합니다:

mkdir -p /root/itemmania-release &&
tar --no-same-owner -xzf /root/itemmania-vps-release.tar.gz -C /root/itemmania-release &&
EXPECTED_CURRENT_SHA256=<사전에 확인한 현재 운영 index.mjs의 SHA256> bash /root/itemmania-release/deploy.sh

대상: /opt/itemmania, itemmania.service, /etc/itemmania.env, ltemmania.com.
다른 설치, 다른 DB, 초기화 활성화, 공개 API 바인딩, 지원하지 않는 서비스 설정은 배포 전에 중단합니다.
기존 회원/지갑/거래 데이터, 업로드, 환경 파일, 원본 소스와 기존 백업은 변경하지 않습니다.
배포 전에 운영 DB 덤프를 생성·검증하고, 실행 파일·업로드·비공개 설정을
/root/itemmania-backups 아래 root 전용 디렉토리에 백업합니다. 외부 백업은 별도입니다.
등록 설정 테이블과 chat_rooms의 구매자·판매자 닉네임 nullable 열만 추가하며,
기존 설정 행과 기존 회원·지갑·거래 기록은 덮어쓰지 않습니다.
현재 관리자/게임 초기화나 전체 DB 스키마 동기화는 실행하지 않습니다.
dist 전체를 검증한 후 원자적으로 교체하고 API 서비스를 잠시 중지/시작합니다.
이전 실행 파일은 위 안전 백업에 보존하지만 자동으로 이전 버전으로 되돌리지 않습니다.
가입 차단은 ON=차단 / OFF=허용이며, 기존 회원 로그인은 계속 허용합니다.
과거 완료 거래는 바꾸지 않으며 이후 거래 완료 정산은 수수료 없이 전액 지급합니다.

실패 시 운영 소스 재빌드나 ALLOW_STARTUP_DB_SYNC=1 설정을 하지 마세요.
서비스 시작 실패는 journalctl -u itemmania -n 50 --no-pager로 확인하세요.
로그를 공유할 때는 비밀번호, DB 연결 문자열, 세션 값을 제거하세요.
